# YORU VK Web 0.2.0 — отдельное приложение без ручного токена

Основная YORU 4.19.1, её собственный плеер, код, данные и кэши не изменяются. Это самостоятельный эксперимент с веб-просмотром, который пользователь разрешил только для отдельного VK-приложения.

## Что изменилось относительно 0.1.0

- Удалены экран ввода токена, TokenParser, TokenVault/Keystore, вызовы users.get/video.search/video.get и зависимость от работоспособности Kate Mobile.
- Удалён прежний Media3-плеер этого прототипа: теперь воспроизведением управляет официальный сайт ВК в стандартном Android WebView или внешний браузер/приложение ВК.
- Остались нативные карточки Shikimori, постеры, описание, связанные тайтлы, русский/оригинальный запрос, выбор номера сезона и серии, дополнительная озвучка в запросе.
- Четыре кнопки поиска: VK Видео (ПК), прямой мобильный VK Видео, Яндекс и Google с ограничением публичными страницами VK. Для каждой есть «В приложении» и «Браузер».
- Прямая ссылка на ролик и официальный video_ext.php. Веб-плеер — дополнительная попытка публичного встраивания; без разрешения владельца/необходимого hash он может не работать. Приложение ничего не подбирает и не извлекает.

## Установка и сценарий

Android 8.0+. APK `apk-output/YORU-VK-0.2.0-prototype.apk`. Название лаунчера **YORU VK Web**, новый applicationId **app.yoru.vk.web**, versionCode 2.

Новый идентификатор выбран, чтобы APK устанавливался рядом с основной YORU и старым тестом 0.1.0 независимо от его временной CI-подписи. **Это не обновление пакета app.yoru.vk.prototype**. Старый «YORU VK» 0.1.0 можно удалить отдельно. Если там был сохранён токен, новое приложение к нему не обращается и удалить его из другого пакета не может; удаление старого приложения и отзыв разрешения в настройках ВК — отдельные действия пользователя.

1. Найти аниме в каталоге Shikimori; для быстрого примера есть «Мастера меча онлайн».
2. Открыть карточку, проверить отдельный тайтл/сезон, ввести серию и при необходимости озвучку.
3. Нажать «Смотреть · найти видео ВК», отредактировать запрос и выбрать способ.
4. На странице сайта выбрать подходящий ролик. Приложение не выдаёт поисковый результат за проверенную серию.
5. Если WebView не поддерживает вход/проигрывание, использовать верхнюю кнопку «Браузер» или вернуться и выбрать другой способ. Внешний chooser может предложить обычный браузер или установленное приложение ВК.

Прямую ссылку можно открыть через WEB → «Открыть ссылку» даже без загрузки каталога. Принимаются ссылки videoOWNER_ID, ссылки с z=video…, а также video_ext.php с переданными владельцем параметрами. OAuth-ссылки с access_token, сторонние домены, HTTP, intent/file/data/javascript и сокращатели не принимаются.

## Веб-экран

- Адрес домена всегда виден; fullscreen — стандартный HTML5-плеер сайта, Back сначала закрывает fullscreen, затем возвращает историю страницы.
- Меню: обновление, начало поиска, мобильная/компьютерная версия, другой способ, копирование запроса, вставка ссылки, удаление веб-сессии.
- Вход — только обычная страница самого сервиса. Приложение не извлекает пароль, cookies или токен, не использует JavaScript-мост и не перехватывает медиапотоки. Внутренний сайт ВК, как любой сайт, использует свою сессию и собственные сетевые методы.
- Cookies и DOM storage — обычное хранилище WebView в отдельном пакете; отключены сторонние cookies, резервное копирование/перенос, file/content-доступ, mixed content и отладка WebView. TLS-ошибки отменяют соединение. Камера, микрофон и геолокация не разрешаются.
- Текст запроса передаётся выбранному VK/поисковику. Открытые сайты могут использовать собственные cookies и аналитику согласно своим правилам.
- Удаление веб-сессии затрагивает только cookies и данные сайтов нового приложения. Не очищает кэш/данные основной YORU или внешнего браузера.
- При уходе приложения в фон WebView уничтожается, чтобы не продолжались видео и звук. При возврате открывается последняя обычная страница, не сохранённая страница авторизации; позиция просмотра может потеряться. Для устойчивого фонового сценария используйте внешний браузер. Поворот веб-экрана не пересоздаёт Activity.

## Ограничения и честность проверки

**Без ручного токена ≠ любое видео без входа.** Удаление, приватность, возрастные/региональные ограничения, CAPTCHA и права ВК сохраняются. Не реализованы обходы, автоматическое решение CAPTCHA, подбор ключей или скачивание закрытых потоков.

Мобильный и компьютерный VK Видео — один сервис, не две независимые видеобазы. Яндекс/Google видят только проиндексированные публичные ссылки, а на сервере проверки показали CAPTCHA. Четыре маршрута не являются обещанием четырёх гарантированно работающих источников. При изменении адресов/кодировки сайта может потребоваться ручной ввод запроса: для этого есть «Скопировать запрос».

Первый Playwright-probe 09.09.2026 выявил преобразование русской строки в legacy-кодировку при перенаправлении vk.com/vkvideo.ru на m.vkvideo.ru; HTTP 200 сам по себе не означает верную выдачу. Повторная проверка подтвердила правильный текст в мобильном поле поиска, но выдача там оставалась в загрузке. В компьютерном режиме получены релевантные карточки «Мастера меча онлайн» без входа. Поэтому основной встроенный маршрут открывается в режиме ПК, а мобильный использует прямой m.vkvideo.ru без проблемного перенаправления. Внешний браузер получает прямой мобильный поисковый адрес; режим ПК в нём выбирается пользователем. Подробные результаты и уровень проверки — в `handoff/YORU-VK-0.2.0-BUILD.ru.md` и JSON evidence.

На физическом Android-устройстве вход и видео не проверялись. Полный авторизованный VK E2E не заявляется. Внешние страницы могут иначе вести себя в Android WebView, чем в Chromium CI. Нет нативного выбора качества/озвучки, скачиваний, календаря или библиотеки основной YORU.

## Сборка и исходник

Java 17, Gradle 8.13, AGP 8.13.2, compile/target SDK 36, min SDK 26. Runtime-библиотек Media3/AndroidX больше нет, используется системный WebView.

```sh
cd yoru-vk-android
./gradlew --no-daemon :app:testDebugUnitTest :app:assembleRelease
# из корня репозитория после успешной сборки/проверки:
python tools/package-yoru-vk.py
```

Выделенный workflow `.github/workflows/build-yoru-vk.yml` собирает только этот проект, проверяет JUnit, подпись и manifest; публичный Shikimori probe отдельно помечается успешным/неуспешным. Исходник ZIP не содержит APK, ключей и Gradle build-каталогов.

APK release/nondebuggable, но пока подписан временным Android Debug сертификатом CI, а не постоянным релизным ключом. Последующие тестовые сборки того же пакета могут потребовать удаления **только YORU VK Web**. Ключи основной YORU не используются.
