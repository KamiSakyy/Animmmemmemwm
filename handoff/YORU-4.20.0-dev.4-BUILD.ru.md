# YORU 4.20.0-dev.4 — исправления озвучек и просмотра

Это продолжение обновления основной YORU. Все36 требований ещё не завершены; не считать этот тестовый APK законченным основным релизом. Основную установку удалять не нужно.

## Исправлено в коде

- Выбранная вручную озвучка сохраняется непосредственно при выборе в обоих плеерах. Сохранение позиции просмотра больше не перезаписывает предпочтение голосом предыдущего или автоматически подобранного потока.
- Программное обновление списка озвучек больше не считается ручным выбором. Полноэкранный выбор открывает существующий оформленный список YORU; доступно управление через кнопку и стандартное действие доступности.
- Автоматический подбор не отключает «только выбранную озвучку». Прямой поток также должен соответствовать этому ограничению; если нужного голоса нет, показывается понятное сообщение.
- Подготовка серии больше не вырезает остальные озвучки из модели на основании прежнего предпочтения. Ручной выбор позволяет явно выбрать другой голос, сохранив строгий режим для нового выбора.
- Массовые фильтры сохраняют нестандартную выбранную озвучку, даже если её нет среди предустановленных названий.
- При обновлении деталей встроенный плеер остаётся на месте между отдельными контейнерами. Перестроение описания/списков больше не удаляет его видеоповерхность из дерева.
- Разрешение, выбранное во встроенном плеере, сохраняется при переходе между сериями текущего просмотра. Ограничение144/240 больше не повышается автоматически до360 при подборе потока.
- Начало последней серии больше не переводит аниме в «Просмотрено». Автоматическая отметка требует известного завершённого статуса и фактически просмотренного конца последней серии.
- Рейтинг в деталях использует подтверждённое происхождение Shikimori; существующая звезда не менялась.
- Системное имя версии очищено от служебных обозначений SDK и сетевой библиотеки. Тестовый характер сборки не скрывается.

## Как подготовлен APK

По прямой просьбе пользователя отдельные unit-тесты, device/emulator и Shikimori-проверки в этой итерации **не запускаются**. Выполняются необходимая оптимизированная сборка APK, подписание и публикация соответствующих APK/исходников. Прежние55 тестов dev.3 нельзя выдавать за проверку dev.4. Поведение исправлений на телефоне пока не подтверждено.

Основной проект сохраняет compile/target37 и Android OkHttp5.5. Для доступного тестового APK используется отдельная совместимая конфигурация compile/target36 и Android OkHttp5.4, min26/code74. Автоматические push больше не повторяют неуспешное получение SDK37; основной job оставлен для явного workflow_dispatch. Требование полноценного SDK37 релиза этим не закрыто.

Сборка из `yoru-android` с настроенной существующей подписью владельца:

```
./gradlew -PverifyOnSdk36 -PcompactApk :app:assembleDebug
```

R8 и удаление неиспользуемых ресурсов сохранены; режим отладки выключен. Ключи не входят в исходный ZIP. Без compact доступна обычная локальная debug-сборка. Результат сборки, исходный commit, размер и SHA256 записываются в `YORU-4.20.0-dev.4-build-report.json`, без ложного отчёта о выполненных тестах.

Кэш, его файлы/ключи/лимиты/алгоритмы и палитра не изменены. Новый RAM-кэш не добавлен. Изменённые предпочтения — пользовательские настройки, не кэш. Отдельный VK-прототип не изменялся. Технические данные пользователя, адреса запросов и тексты исключений в пользовательские надписи не добавляются.

## Выдача и ограничения

APK и отдельный source ZIP публикуются прямыми assets GitHub Releases. Если установлена старая тестовая копия с временной подписью, перед её переустановкой сохраните данные. Основную YORU не удаляйте.

Оставшиеся требования находятся в `YORU-PRODUCTION-36-STATUS-2026-09-14.ru.md`. В том числе ещё нужны поведение на устройстве, завершение preflight до просмотра/отложенных скачиваний, полнота жанров всех провайдеров, проверка обоев и фонового экспорта, metadata без известных ID и основной релиз. Недоступные в API просмотры по озвучкам не выдумываются.
