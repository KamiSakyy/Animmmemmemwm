# YORU 4.21.0 → 4.49.0 — сводка непрерывной работы 15 сентября 2026

Ветка: `arena/01a0a14a-animmmemmemwm`. Все 28 релизов собраны одним и тем же workflow (push → `build-apk.yml` → GitHub Release), каждый APK проверен локально по репозиторной копии в `apk-output/`.

## Как проверялся каждый APK

Одинаково для всех версий:

- количество записей в ZIP — 393, все со способом `STORED` (без сжатия);
- в `AndroidManifest.xml` (UTF‑16‑LE) присутствует `app.yoru.mobile.debug` и ожидаемый `versionName`;
- набор сертификатов в signing-блоке совпадает с предыдущей версией (обновление ставится поверх);
- контрольные суммы `sha256` пересчитаны и записаны рядом (`apk-output/*.sha256`), `sha256sum -c` проходит.

Ни один APK не запускался на устройстве и не проверялся в эмуляторе — в этой среде это невозможно.

## Что осталось открытым

1. **Проверка на устройстве.** Ничего из перечисленного не запускалось на телефоне: нет ни устройства, ни эмулятора. Особенно это касается жестов (перемотка, яркость/звук), PiP, виджета, сохранения в галерею и уведомлений.
2. **Данные о популярности озвучек у Shikimori.** Требуется подтверждение со стороны API/источника — из кода это не решается. Не заявляется сделанным.
3. **OkHttp 5.5 и сборка под SDK 37.** Внешнее ограничение инструментов и зависимостей. Не заявляется сделанным.
4. **Точный размер для части потоков.** Там, где плейлист шаблонный (SegmentTemplate) или сервер не отдаёт `Content-Length` даже на ranged-запросе, остаётся «Размер неизвестен». Это честный ответ, а не оценка.
5. **Работа источников и провайдеров.** Не проверялась и не проверяется из этой среды.

## Полезные мелочи

- Сборка падала дважды за ночь по не зависящим от кода причинам: сетевой сброс при скачивании зависимостей Gradle (4.33.0) и истёкший токен GitHub в песочнице (момент с 4.44.0, после восстановления доступа проверен). Обе ситуации закрыты.
- В workflow заменён сломанный экшен установки Android SDK на прямую установку command-line-tools; при падении сборки в ветку сохраняется `ci-logs/last-failure.txt` (логи Actions из этой среды недоступны), после использования каталог удаляется.
