# YORU 4.20.0-dev.1 — первый рабочий checkpoint

**Не production-релиз и не завершение всех 36 требований.** База — YORU 4.19.1/code70; изменения — 4.20.0-dev.1/code71. Основной код проверен на commit `458611f032c05e2bc4a2b275d6e274880f8c104e`.

## Что изменено

- Главная на RecyclerView: топ Shikimori по 6, дневная рекомендация, pull-to-refresh и foreground-таймер. Старые персональные блоки сохранены.
- Общий HttpTransport на OkHttp 5.5.0 для прежних native HTTP-вызовов; Media3 OkHttpDataSource; закрытие активных Call при отмене TaskQueue; защита чувствительных заголовков при cross-origin redirects.
- Карточки: score вместо озвучки, прежний символ звезды, без полосы прогресса. Позиция просмотра сохраняется.
- Жанры Shikimori загружаются из справочника, включая взрослые категории. Жанры в деталях кликабельны; неизвестное сопоставление не подменяется чужим ID.
- Подсказки поиска с обложками, анимация панели, мини-обложки точных локальных совпадений в истории. Для неизвестного запроса — иконка поиска, не случайное аниме.
- Календарь: pull/hourly, МСК либо системная зона, корректные дни при переходах летнего времени. Выбор зоны — в настройках.
- Убраны UI-надписи Quality+, добавлены 2K/4K, настройка «Разрешение». Реальная подпись 144/240 не округляется до 360; неизвестный Sibnet не называется 480.
- Убраны приблизительные размеры: когда размер не получен, интерфейс говорит «Размер неизвестен». Полное вычисление точного размера ещё впереди.
- Крестик фильтров, контейнеры выбора, минималистичная иконка настроек, обновлённая корзина с48dp, удалена верхняя «История» в каталоге/коллекции.
- Новые загрузки постеров сначала пробуют high-quality URL без dataSaver; декодирование ограничено по памяти без перекодирования raw bytes.

**Не изменены** RGB-палитра, дисковые ключи/лимиты/TTL/очистка кэшей, сохранение позиции и отдельный VK-прототип. Новый RAM-кэш не добавлен. Полное устранение синхронного декодирования/мерцания ещё не выполнено.

## Почему нет нового release APK

Billing уже не блокирует runner. Требуемый SDK37 job `103889120912` остановлен **до Gradle**:

```
Warning: Failed to find package 'platforms;android-37'
```

Ответ воспроизведён с `sdkmanager --channel=3`. Android AAR OkHttp5.5.0 действительно требует compileSDK37; это подтверждено `checkDebugAarMetadata`. Не выполнена подмена android.jar, не переименован SDK36 в37, старый APK4.19.1 не выдан за новый.

Конфигурация основного проекта: compile/target37, AGP9.2.1, Gradle9.4.1, JDK17, build-tools36.0.0. Матрица AGP официально допускает API37: https://developer.android.com/build/releases/agp-9-2-0-release-notes . Наличие документации не гарантирует доступность платформенного пакета в SDK Manager.

## Исходники и сборка

Архив `YORU-4.20.0-dev.1-source.zip` содержит проект, workflow, реестр требований, этот документ и evidence CI. APK, signing keys, owner-signing, build и локальные инструменты исключены. Стабильный source ZIP4.19.1 не перезаписан.

Для проверки общего Java-кода после установки SDK36/JDK17:

```
cd yoru-android
./gradlew --no-daemon -PverifyOnSdk36 :app:testDebugUnitTest :app:assembleDebug
```

Версия такого debug: `4.20.0-dev.1-verification-sdk36`, пакет `.debug`. CI не публикует его как release APK. Для настоящей SDK37-сборки убрать флаг, установить реальный SDK37 и использовать собственную release-подпись; закрытые ключи не входят в архив.

## Что ещё не готово

Общий inline native player под описанием, связность сезонов, SAF, точные размеры ресурсов/HLS, редактор обоев, новые жесты/lock/PixelCopy, полная reconciliation эпизодов и перенесённых дат, полные справочники остальных провайдеров и сохранение metadata истории поиска.

Фактический статус каждого пункта: `YORU-PRODUCTION-36-STATUS-2026-09-14.ru.md`. Непроверенные функции не отмечены как production-ready.
