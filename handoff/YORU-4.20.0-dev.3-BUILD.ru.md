# YORU 4.20.0-dev.3 — продолжение тестового обновления

Это отдельная тестовая копия основной YORU, не завершение всех36 требований. Основную установку удалять не нужно. При переходе со старой тестовой копии с временной подписью сначала сохраните её данные; может потребоваться переустановка только тестовой копии.

## Изменения

- Массовое скачивание сначала готовит варианты и показывает подтверждение. До подтверждения ни одна серия не добавляется в загрузки.
- Будущие серии, дубли и номера за пределами подтверждённого сезона исключаются. После получения потока повторно сверяются номер серии, известные идентификаторы аниме и выбранная строгая озвучка.
- Проверяется точный размер каждого подходящего файла. Общая сумма выводится только при известном размере всех файлов; неизвестный размер не подменяется оценкой. Сумма защищена от переполнения.
- Подтверждение показывает число доступных/не найденных серий, выбранные озвучки и разрешения, размеры и предупреждение о мобильной сети. Подготовку можно отменить.
- Фильтры скачивания закрываются крестиком вместо «Отмена». Папки коллекции оформлены контейнерами с прежней палитрой.
- Сохраняются предыдущие исправления полноэкранного выбора озвучки/разрешения, кадров, обложек, календаря и пользовательских надписей.

## Размер, приватность и сборка

APK по-прежнему оптимизируется с R8 и удалением неиспользуемых ресурсов, без режима отладки и с постоянной подписью владельца. Неоптимизированная сборка8,87 МБ больше не выдаётся. Фактический размер нового APK находится в `YORU-4.20.0-dev.3-size-report.json`.

Существующие кэши, их лимиты, ключи, файлы и алгоритмы не изменены. Списки подготовленных вариантов — только живое состояние операции выбора, не новый RAM-кэш. Цвета сохранены. В пользовательские надписи не добавлены технические данные устройства, адреса запросов, исключения или служебные параметры сборки.

Основной проект остаётся compile/target37 и Android OkHttp5.5. Проверочный APK использует compile/target36 и Android OkHttp5.4; min26, code73. Это не замена требованию SDK37 и не проверка поведения Android17. Получение SDK37 в CI остаётся блокером основной сборки.

Из `yoru-android`:

```
./gradlew -PverifyOnSdk36 -PverifyJvmTransport :app:testDebugUnitTest
./gradlew -PverifyOnSdk36 -PcompactApk :app:testDebugUnitTest :app:assembleDebug
```

Компактная сборка требует настроенной подписи владельца; её ключей нет в source ZIP. Без `-PcompactApk` доступна обычная локальная debug-проверка. Release task с проверочным SDK36 запрещён.

## Выдача

APK и соответствующий source ZIP публикуются отдельными assets GitHub Releases. Перед публикацией проверяются SHA256, результаты JUnit, манифест архива, отсутствие ключей/артефактов сборки внутри исходников и совпадение всех Android-файлов с commit, из которого собран APK. Не публиковать ссылки на отсутствующие assets.

## Что ещё не закрыто

Все36 требований остаются в `YORU-PRODUCTION-36-STATUS-2026-09-14.ru.md`. Обязательный preflight перед просмотром и отложенные скачивания требуют дальнейшей работы. Для потоков без сообщённого полного размера остаётся честное неизвестное значение. Нужны device-проверки плеера, SurfaceView, PiP, rotation, обоев и фонового экспорта. При недоступности той же озвучки точный fullscreen handoff не гарантирован. Полнота жанров остальных провайдеров и metadata без известных ID ещё проверяются. Просмотры по озвучкам из Shikimori не выдумываются.

Live Shikimori/emulator probes не выполнялись. Отдельный VK-прототип и его работающий просмотр прямых ссылок не изменены.
