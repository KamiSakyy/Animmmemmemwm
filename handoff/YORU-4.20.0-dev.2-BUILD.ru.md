# YORU 4.20.0-dev.2 — совместимый тестовый checkpoint

Это продолжение основной YORU 4.19.1, не отдельный VK-прототип и не завершённый production-релиз по всем36 требованиям.

## Что устанавливается

`apk-output/YORU-4.20.0-dev.2-compat-sdk36-okhttp5.4.apk` — явно совместимая оптимизированная тестовая Android-сборка: compile/target36, min26, официальный Android OkHttp5.4.0. Название в системе: **YORU · проверка**, пакет `app.yoru.mobile.debug`. Устанавливается отдельно от основной YORU; данные основной установки не заменяет. Режим отладки выключен, используются R8, удаление неиспользуемых ресурсов и существующая постоянная подпись владельца. Проверка подписи сравнивает также пакет конкретного варианта; основная конфигурация по-прежнему проверяет основной пакет.

Предыдущая тестовая копия подписывалась временным ключом: при переходе с неё может потребоваться переустановка именно тестовой копии. Сначала сохраните её данные средствами приложения. Основную YORU удалять не нужно.

Основная конфигурация исходников сохранена: compile/target37, Android OkHttp5.5.0, AGP9.2.1, Gradle9.4.1. SDK37 release не получен: sdkmanager в CI не находит `platforms;android-37`, включая channel3. Совместимый APK не закрывает это требование и не является проверкой поведения Android17.

JVM5.5 профиль используется только для unit/compile проверки. Его APK не выдаётся как Android-сборка. Для совместимого APK отдельно выполняются Android5.4 build и JVM unit-тесты с этой зависимостью; это всё ещё не тесты устройства.

## Изменения относительно dev.1

- Собственный inline-плеер под описанием, выбор серий, озвучки, разрешения и связанных частей; общий native Media3 backend с полноэкранным плеером.
- Блокировка управления, жесты яркости/громкости, PixelCopy именно видеоповерхности. Одновременно сохраняется не более одного кадра.
- Выбор фото через системный picker/SAF, crop/resize, прозрачность и макетный preview вкладок перед сохранением обоев. Палитра не заменена.
- Progressive видео экспортируется в выбранную системным проводником папку через сохраняемую очередь WorkManager. Приватный журнал позволяет повторить прерванное копирование с очисткой его частичного документа; завершённая операция идемпотентна. Исходная офлайн-загрузка не удаляется.
- Рейтинги с подтверждённым происхождением Shikimori; существующая звезда сохранена. EpisodeRules нормализует уникальные доступные серии и подтверждённый total. Будущие UI-заглушки не стирают потоки и не увеличивают total.
- Известные конфликтующие MAL/AniList ID защищают от объединения разных сезонов. Календарь заменяет перенесённое событие, не выдумывает weekly/hash даты; для date-only пишет «время уточняется».
- Дочерние HTTP pools поддерживают отмену активных запросов. Kodik учитывает144p, только если поток реально присутствует.
- Cached poster decode перенесён с UI в существующий worker, drawable при повторном same-key binding сохраняется, системная иконка-заглушка убрана. Файлы/ключи/лимиты/TTL/алгоритм кэша не изменены, RAM-кэш не добавлен.
- История поиска сохраняет metadata реально выбранного аниме для маленькой обложки. Это пользовательская история с прежним лимитом14 запросов, очисткой и запретом записи в private mode; произвольному запросу чужой постер не назначается.

Локально проверены выключенный режим отладки, совпадение сертификата с существующей подписью владельца, сохранность имени Worker для фонового экспорта и ZIP CRC. Значения ключей/сертификата в отчёт не выводятся.

Точный source commit, run ID и фактически разобранные JUnit XML counts находятся в `YORU-4.20.0-dev.2-verification-tests.json`; состояния jobs — в `YORU-4.20.0-dev.2-ci-jobs.json`.

Сборка основной конфигурации требует установленного настоящего SDK37 и владельческой подписи для release. Проверочные команды из `yoru-android`:

```
./gradlew -PverifyOnSdk36 -PverifyJvmTransport :app:testDebugUnitTest
./gradlew -PverifyOnSdk36 -PcompactApk :app:testDebugUnitTest :app:assembleDebug
```

Компактная сборка требует настроенной подписи владельца; её ключи не входят в source ZIP. Без `-PcompactApk` доступна обычная локальная debug-проверка. Release task с `-PverifyOnSdk36` запрещён. Source ZIP исключает ключи, owner-signing, APK, build и .gradle; содержит SHA256-манифест файлов. Стабильные APK/ZIP4.19.1 не перезаписаны.

## Что остаётся открытым

Все36 ещё не завершены. Полный реестр — `YORU-PRODUCTION-36-STATUS-2026-09-14.ru.md`.

- При переходе inline→fullscreen теперь передаются выбранная озвучка, разрешение и запрос полноэкранного режима. На следующей серии сохраняется предпочтение озвучки. Если тот же вариант недоступен, точное совпадение не гарантируется. Требуется проверка SurfaceView, сезонов, PiP, lock, жестов и rotation на устройстве.
- Для ручного скачивания одной серии добавлен cancellable preflight и подтверждение точного числа байт либо неизвестного размера. Массовые/отложенные скачивания и обязательный preflight перед просмотром ещё требуют работы. Для HLS/DASH честно неизвестный размер; они остаются в офлайн YORU, не конвертируются и не маскируются под MP4.
- SAF требует проверки process death, отзыва доступа, нехватки места и cloud document providers. WorkManager подчиняется ограничениям Android; моментальный фоновой экспорт не обещается. Микропромежуток между createDocument и сохранением journal не атомарен.
- Preview обоев использует макеты вкладок; реальные recycler-фоны и восстановление состояния требуют проверки. Полнота справочников всех провайдеров и metadata без известных ID ещё проверяются.
- В проверенной Shikimori API-схеме нет просмотров по озвучкам. Такие числа не выдуманы.

Live Shikimori и emulator probes не выполнялись. Рабочее воспроизведение прямых ссылок отдельного VK-прототипа не изменялось.

Причина исходного скачка размера: было ошибочно сопоставлено 2 664 056 байт прежнего release с 8 868 325 байт нового неоптимизированного debug. Прежний debug уже занимал7 577 250 байт. Новые библиотеки также увеличили размер; размер итогового оптимизированного APK и детализация ZIP фиксируются в `YORU-4.20.0-dev.2-size-report.json`. Не обещается возврат к прежнему размеру без измерения.

В пользовательских надписях окна «О приложении» и профиля используется обычная версия, без SDK/transport suffix. Убраны обозначения HLS/DASH и путь Pictures из новых уведомлений. Не выводятся исключения, адреса запросов или идентификаторы устройства. Проверка исходников не обнаружила добавленного сбора ANDROID_ID, модели/производителя/отпечатка устройства либо SDK аналитики; это не утверждение об отсутствии всех сетевых метаданных на стороне источников.
