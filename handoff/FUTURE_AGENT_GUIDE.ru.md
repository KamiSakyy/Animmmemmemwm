# Памятка будущему агенту YORU

Текущий продукт: Java Android `app.yoru.mobile` в `yoru-android/app`, актуальная линия 4.12.0. Kotlin удалён из сборки и не должен возвращаться без прямой команды пользователя.

# YORU — гайд для будущего агента

Говорить с пользователем на русском. Пользователь хочет видеть этапы и проценты: коротко писать, что делается, без молчания на долгих шагах.

## Важное исправление 4.12.0

Выбранная озвучка по умолчанию — это приоритет, а не причина падать. Если пользователь выбрал AniLibria.TV, но у тайтла/серии есть только другая реальная озвучка, YORU обязан скрыто обнаружить доступные голоса и открыть/скачать рабочий вариант. Нельзя завершать сценарий сообщением “серия недоступна” только из-за отсутствия выбранного голоса.

Карточки и детали должны показывать статус тайтла и прогресс выхода серий: `Вышло X из Y`. Для онгоингов нужно использовать индивидуальное расписание (`nextEpisodeAt`, если доступно), а невышедшие серии показывать как future-заглушки с датой/уточнением, без обычного play/download-вида.

## Главная цель проекта

YORU — удобное Android-приложение для просмотра аниме. Главные приоритеты: стабильность, скорость, минимализм, удобные серии, реальные озвучки, быстрые загрузки, сильный YORU и один нативный YORU Player.

## Важное исправление 4.5.1

Нельзя считать внутренние маршруты озвучками.

Не являются озвучками:

- бренд приложения и автоматический слой;
- внутренние резервные маршруты;
- названия технических плееров и провайдеров;
- названия потоковых форматов, ссылок, iframe/player/provider/source.

Озвучки — это реальные названия голосов/команд, которые пришли у конкретного аниме/серии, например:

- AniDUB;
- AniLibria.TV / AniLiberty;
- AniMaunt;
- AnimeVost;
- AniStar & DEEP;
- Beyond:Studio;
- Dream Cast;
- AniMedia;
- StudioBand;
- JAM;
- SHIZA Project;
- другие реальные названия, если они доступны у серии.

Для каждого аниме и каждой серии список должен строиться динамически: показывать только доступные реальные озвучки. Если выбран режим «Показывать только выбранную озвучку», остальные голоса скрываются в плеере и загрузках.

## Маршруты

Пользователю не показывать технические маршруты. YORU — основной скрытый автоматический слой. Резервные маршруты могут дополнять под капотом, но не должны называться озвучками.

Если маршрут ломается, YORU должен пробовать другой маршрут без вывода технической панели.

## Плеер

Один пользовательский плеер — нативный YORU Player. Не возвращать большие кнопки под видео и не включать стандартные ExoPlayer controls одновременно с YORU overlay. Fullscreen должен быть настоящим fullscreen/landscape без панелей приложения.

## Скачивание

Перед скачиванием показывать фильтры:

- доступные озвучки конкретной серии;
- 360p / 480p / 720p / 1080p / лучшее доступное.

Не перебирать все маршруты без необходимости. Сначала выбранная озвучка и разрешение, потом скрытый резерв только если нужен.

## Что не возвращать

Не возвращать нерабочие направления, лишние центры, игровые счётчики, VPN-функции, конвертацию видео, старые отдельные категории маршрутов, бесполезные настройки и маркетинговые обёртки.

## Рабочий процесс

1. Изучить код перед правками.
2. Сделать изменения в исходниках.
3. Проверить Java parse и `git diff --check`.
4. Проверить, что в пользовательских текстах нет старых запрещённых названий и что маршруты не называются озвучками.
5. Только потом bump версии и один release APK build через GitHub Actions.
6. Не просить GitHub токены/пароли. Если auth сломан — попросить переподключить GitHub в Arena.
