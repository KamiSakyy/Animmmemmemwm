# YORU dev.11 — объединённое обновление

Основа — подтверждённая пользователем dev.9 без минификации и исправления списка серий dev.10. Не полное восстановление старого приложения dev.7: Application остаётся прежней, DetailsActivity сохраняет независимые загрузки и постоянные секции, MainActivity и InlinePlayer адаптированы по месту. Отдельные ранее разработанные компоненты повторно использованы после сопоставления интерфейсов.

## Объединённые изменения

- Тихое обновление главной/каталога, дневная рекомендация, сохранение строк и позиции, отмена ненужных задач.
- Жанры: полный полученный справочник, поиск/алиасы, провайдерские IDs, прямой переход из деталей, взрослые жанры не скрываются.
- Озвучки: точное/нестандартное предпочтение, явный выбор без сброса строгого режима временным fallback. Разрешение, пауза, позиция и lock сохраняются при переходах/пересоздании плеера.
- Размер подготавливается до нативного просмотра/скачивания; неизвестный размер остаётся неизвестным. HLS/DASH parser учитывает аудио, наследуемое разрешение и отмену.
- Серии: сохраняется список dev.10; авторитетный total, нет молчаливого выбора соседней серии, завершение тайтла только у конца последней серии.
- Расписание: МСК/местная зона и перенос даты будущих загрузок из календаря; ограниченные фоновые задачи с выбранной озвучкой/разрешением.
- SAF: progressive и перенос совместимых офлайн адаптивных аудио/видеодорожек без перекодирования; foreground-уведомление, отмена в карточке, журнал и уборка временных файлов при открытии загрузок. Субтитры не переносятся, DRM/несовместимые форматы могут не поддерживаться.
- Обои: системный picker, crop/resize, прозрачность и read-only предпросмотр реальных вкладок до Save.
- Коллекции/жанровые фильтры оформлены контейнерами; палитра и звезда сохранены.

## Что не менялось

Application/YoruApp, MediaCache, YoruCache и ImageLoader не заменены. Кэш, его TTL/лимиты и алгоритмы не перерабатывались. Нового RAM-кэша нет. Отдельный VK-проект не менялся. SDK/зависимости плеера не обновлялись ради размера; добавлен только Transformer1.5.1 для поддерживаемого экспорта.

## Сборка

Минификация и resource shrink отключены, все записи финального APK — STORED, без ZIP-сжатия. Подпись выполняется после выравнивания; после подписи APK не меняется. code81 позволяет обновление поверх предыдущих тестовых копий. Данные не удалять.

```
./gradlew --no-daemon -PverifyOnSdk36 -PownerSignedApk :app:assembleStoredDebug
```

Ключи владельца в source ZIP не включены. Сжатие ZIP исходников не относится к запрету сжатия APK.

## Ограничения

Новых unit/device/provider-прогонов нет. Сборка не доказывает работу на устройстве. Полный реестр36 требований приведён отдельно, без выдуманного общего процента приёмки. SDK37/последний Android OkHttp не закрыты совместимой SDK36/OkHttp5.4 сборкой. Просмотры озвучек Shikimori не предоставляет; точный размер неизвестного адаптивного потока не выдумывается. Полнота ответов всех провайдеров не подтверждена.
