# YORU 4.20.0-dev.7

Продолжение основной базы4.19.1 и опубликованной dev.6. Отдельная тестовая установка; основную YORU удалять не нужно.

## Изменения

- Подтверждённые идентификаторы жанров Shikimori сохраняются вместе с метаданными тайтла и передаются при переходе из деталей в каталог. При наличии ID фильтр применяется до первого запроса, без повторного поиска по переводу названия.
- Для старых записей без ID остаётся сопоставление по нормализованному названию и алиасам справочника.
- Быстрые кнопки «Экшен», «Комедия», «Романтика», «Фэнтези» используют справочник выбранного источника. Shikimori ID больше не применяется к AniLibria/Yummy. Запоздалый ответ после смены экрана/источника игнорируется.
- Сохраняются изменения dev.6: выбор озвучки/разрешения, ограничения количества серий, офлайн экспорт совместимых HLS/DASH в выбранную папку без перекодирования, отмена сохранения, обновление дат будущих загрузок, реальный предпросмотр обоев.

## Ограничения

Только необходимая оптимизированная сборка и публикация пары APK/ZIP. Отдельные unit/device/emulator/provider прогоны не выполнялись. Отчёт сборки приложен отдельно.

Совместимый APK использует SDK36 и Android OkHttp5.4, code77. Настройки основного проекта — SDK37/OkHttp5.5; соответствующая сборка остаётся заблокирована доступностью платформы. Совместимый APK не закрывает это требование.

Просмотры по озвучкам Shikimori не предоставляет. Точный размер адаптивных потоков до загрузки может быть неизвестен. Полнота ответов сторонних провайдеров и работа на устройстве не подтверждены. Все36 требований не объявляются принятыми.

Кэш, его алгоритмы и лимиты не менялись. RAM-кэш не добавлялся. Палитра и отдельный VK-плеер сохранены. Ключ подписи в ZIP не включается.
