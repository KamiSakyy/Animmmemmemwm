# YORU dev.10 — список серий

Продолжение dev.9, запуск которой пользователь подтвердил рабочим. Не возврат всего кода dev.3–dev.7. Runtime-изменения ограничены DetailsActivity и InlinePlayer; запуск Application/MainActivity, зависимости и кэш не менялись.

## Что изменено

- Блок «Серии» расположен сразу после встроенного плеера, до скриншотов, трейлера и дополнительных сведений. Есть отдельная кнопка перехода к списку.
- Постоянные секции страницы не отсоединяют PlayerView при обновлении описания/метаданных.
- Метаданные и плейлист загружаются независимыми отменяемыми задачами. Убрана отмена позднего плейлиста после ожидания 2.6/8 секунд в задаче метаданных. Старый ответ после повторной загрузки или закрытия экрана не применяется.
- При обновлении метаданных полученные серии сохраняются через существующие правила идентичности/нумерации. Если источник недоступен, видны сообщение и кнопка повторной загрузки.
- NestedScrollView поддерживает вложенную прокрутку RecyclerView серий. Ограничение высоты блока не удаляет остальные элементы списка.
- Для законченных тайтлов не создаётся список будущих серий только из-за временно пустого плейлиста.
- Полученный плейлист передаётся встроенному меню серий. Открытие меню до загрузки сначала получает список и показывает выбор, не запуская автоматически первую серию.
- Ручной выбор озвучки во встроенном плеере сохраняется сразу. Прочие механизмы выбора озвучки ещё не объявляются полностью исправленными.
- Удалена оставшаяся подпись QUALITY+ в заголовке деталей.

## Сборка и установка

Минификация и resource shrink выключены, все записи APK — STORED без ZIP-сжатия. Подпись прежняя, code80 позволяет обычное обновление поверх dev.9. Приложение и данные не удалять. Кэш, палитра и отдельный VK-плеер не менялись.

Команда для подписанной сборки с настроенными, не входящими в архив ключами владельца:

```
./gradlew --no-daemon -PverifyOnSdk36 -PownerSignedApk :app:assembleStoredDebug
```

Отдельные unit/device/provider прогоны не выполнялись. Пользователь подтвердил dev.9, не dev.10; успешная сборка не подменяет подтверждение поведения на телефоне. Доступность конкретного плейлиста зависит от источника. Все36 требований ещё не завершены.
