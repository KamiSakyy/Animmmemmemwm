# YORU VK Web 0.2.0 — способы без ручного access token

Дата: 09.09.2026, местное время пользователя. Это новая версия отдельного эксперимента, а не изменение стабильной YORU 4.19.1.

## Установить и пользоваться

- APK: `apk-output/YORU-VK-0.2.0-prototype.apk`.
- Исходник: `handoff/YORU-VK-0.2.0-source.zip`.
- Лаунчер: **YORU VK Web**. Новый пакет **app.yoru.vk.web**, versionCode 2, min Android 8.0.
- Устанавливается рядом с основной YORU и старым «YORU VK» 0.1.0: не зависит от подписи старого тестового пакета. Старый токенный прототип можно удалить отдельно; новая версия не читает его данные. Основную YORU удалять или переустанавливать не нужно.

Карточка Shikimori → номер сезона/серии и озвучка → «Смотреть · найти видео ВК» → способ → выбор ролика на самом сайте. Русское и оригинальное название переключаются; запрос редактируется. Автоматического подтверждения соответствия серии нет.

## Реализованные способы

| Способ | Реализация | Что проверено и чего не обещаем |
|---|---|---|
| VK Видео, режим ПК | Официальная страница поиска в WebView с desktop user agent; масштабирование и HTML5 fullscreen | В Chromium CI без входа получена релевантная выдача «Мастера меча онлайн». Это проверка выдачи, не воспроизведения/прав на конкретную серию. Основная рекомендуемая кнопка |
| VK Видео, мобильный | Прямой `m.vkvideo.ru/?q=<UTF-8>&action=search`, без проблемного старого редиректа | Поле содержит правильный русский запрос; появились подсказки. Список результатов в отведённое время оставался в загрузке. Не выдаётся за подтверждённый успешный поиск |
| Яндекс | Поиск публичных страниц `site:vkvideo.ru/video OR site:vk.com/video` | На IP CI — CAPTCHA. В приложении нет автоматического решения; пользователь может воспользоваться своим браузером |
| Google | Другой поисковый индекс с тем же ограничением сайтов | На IP CI — CAPTCHA / unusual traffic. Это резервный маршрут, не обещание доступности |
| Прямая ссылка | Страница videoOWNER_ID, z=video…, либо официальный video_ext.php с предоставленными параметрами | Разбор/ограничение ссылок проверены unit-тестами. Веб-плеер без разрешения встраивания или нужного hash может не открыться; ничего не подбирается |
| Внешний браузер / приложение ВК | HTTPS ACTION_VIEW с системным выбором обработчика; доступен на каждом способе и внутри веб-экрана | Использует обычную сессию выбранного браузера/приложения, не cookies WebView. Фактический состав chooser зависит от установленных приложений |

Мобильная и ПК-версия — **один сервис ВК**, а не независимые видеокаталоги. Яндекс/Google не открывают закрытые, удалённые или неиндексируемые записи. Обычный вход ВК, региональные ограничения, CAPTCHA и правила правообладателей сохраняются.

## Исправление кодировки

Первый публичный probe показал, что `vk.com/video?...q=<UTF-8>` и `vkvideo.ru/?q=<UTF-8>` при мобильном UA переводятся в `m.vkvideo.ru` с Windows-1251-процентами (`%CC%E0…` вместо `%D0%9C…`). Среди результатов появились нерелевантные «F2/F3». Такой HTTP 200 **не был принят за работающий поиск**.

Повторная проверка прямого мобильного URL сохранила правильную строку. Компьютерный режим с отправкой через обычное поле сайта дал карточки нужного аниме. Поэтому встроенная основная кнопка использует ПК-режим, мобильная — прямой UTF-8 URL, а старый vk.com оставлен только как поддерживаемый формат прямых ссылок на ролики, не как основной поисковый маршрут.

Кнопка внешнего браузера переводит поисковый URL в прямой мобильный, чтобы не повторять legacy-редирект. Если на телефоне мобильный сайт зависает, пользователь может включить ПК-версию в своём браузере. Меню WebView также умеет менять режим и адрес поиска, копировать запрос и возвращаться к другим способам.

## Почему заменена архитектура

Новости апреля 2026 о массовом ограничении функций Kate Mobile требуют не полагаться на старые схемы токенной авторизации. Источник: Trashbox, 28.04.2026, со ссылкой на заявление разработчиков от 27.04.2026:

- https://trashbox.ru/link/2026-04-28-bolshe-nelzya-lajkat-vk
- https://vk.com/wall-26062647_948767

Указанный перечень не доказывает буквальное отключение всех VK API методов. Для этой версии спор не влияет на работоспособность архитектуры: **TokenParser, TokenVault, экран токена, native users.get/video.search/video.get и Media3 удалены**. Нативный API-код теперь только Shikimori. Сайт VK внутри WebView сам управляет своим входом и внутренними запросами, как в обычном браузере.

## Безопасность и границы

- Новый пакет не получает доступ к основной YORU или старому токенному прототипу.
- Нет JavaScript-моста, чтения cookies/паролей нативным кодом, извлечения медиапотоков, обхода TLS/CAPTCHA, file/content доступа, HTTP/mixed content.
- Верхний домен виден; внутри разрешены только HTTPS-страницы доменов VK и выбранных поисковиков. Переходы на другие сайты и произвольные intent-схемы блокируются.
- Cookies/DOM storage — штатные данные сайтов только нового WebView; сторонние cookies запрещены. Удаление веб-сессии очищает только эти данные, не основной кэш YORU и не браузер.
- Разрешение приложения: INTERNET. Резервное копирование и перенос выключены, WebActivity nonexported, APK nondebuggable, WebView debugging выключен.
- При фоне WebView уничтожается для остановки видео/звука. Возврат перезагружает последнюю обычную страницу; позиция видео не сохраняется. Поворот веб-экрана не пересоздаёт Activity.
- Это веб-прототип, не встроенный плеер основной YORU. Нет новых RAM/дисковых медиакэшей, загрузчика серий, календаря или библиотеки.
