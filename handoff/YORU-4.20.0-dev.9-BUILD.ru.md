# YORU dev.9 — новая основа из dev.2 без минификации и сжатия

По прямому требованию пользователя за основу взят runtime-код опубликованной YORU-4.20.0-dev.2-compat-sdk36-okhttp5.4, которую он подтвердил рабочей. Изменения dev.3–dev.7 не включены. Последующие обновления должны разрабатываться заново с этой основы, а не переноситься пакетом из проблемных версий.

## Правила этой и последующих сборок

- Минификация отключена в debug и release.
- Удаление неиспользуемых ресурсов отключено в обоих вариантах.
- Опубликованный APK содержит только STORED ZIP entries: без ZIP-сжатия DEX, ресурсов, assets и прочих записей.
- Подпись производится после записи несжатого APK и выравнивания. После подписи APK не перепаковывается.
- Прежний compactApk запрещён. Для подписанного распространения используется отдельный ownerSignedApk, не включающий оптимизацию.
- Задачи assembleStoredDebug и assembleStoredRelease задают одинаковое правило для будущих тестовых и основных обновлений.

Исторический факт: опубликованная компактная dev.2 была минифицированной. Новая dev.9 намеренно отличается её сборочными настройками по последнему требованию пользователя. Отсутствие минификации и сжатия увеличивает размер; это не добавленные функции или новая библиотека плеера.

## Совместимость данных

Сохранены package тестового варианта и подпись владельца. Номер повышен до79 для установки поверх поздних версий без удаления приложения. БД будущих загрузок оставлена версии2 с дополнительным date_label: это единственная совместимость runtime-кода поверх dev.2, необходимая для открытия уже созданных планов без ошибки понижения схемы. Данные не сбрасываются, таблица не удаляется. Код кэша и его алгоритмы не перерабатывались.

## Сборка исходников

Linux, JDK17, Android SDK36 и build-tools36.0.0. Ключи владельца не включены в ZIP. Для официального подписанного APK используются настроенные owner-signing файлы и команда:

```
./gradlew --no-daemon -PverifyOnSdk36 -PownerSignedApk :app:assembleStoredDebug
```

Без ключей владельца можно собрать собственную локальную debug-копию, но она не является официальным обновлением и не должна устанавливаться поверх пользовательских данных с другой подписью. Обычная assembleDebug также не включает минификацию/удаление ресурсов; гарантированно несжатый дистрибутив создаёт assembleStoredDebug.

## Что не утверждается

Новых unit/device/provider прогонов нет. Компиляция и упаковка не доказывают запуск на телефоне пользователя и не устанавливают точную причину прежнего вылета. Полный набор36 требований не завершён. SDK37 остаётся настройкой основного проекта, но опубликованный вариант собирается с SDK36/Android OkHttp5.4 как выбранная основа. Сжатие отдельного архива исходников не относится к запрету сжатия APK.
