# YORU 4.19.0 — сборка и передача

Дата: 2026-09-09. База: проверенный `YORU-4.17.2-stable-source.zip`.
Версия: 4.19.0, versionCode 69. Ветка: `arena/01a0828d-animmmemmemwm`.

## Возможности

Будущая серия в карточке → «Скачать после выхода». Также кнопка скачивания у события календаря.
Выбор озвучки и разрешения сохраняется в отдельной постоянной SQLite-очереди. «Любая доступная» и «Лучшее доступное» — явно выбираемые режимы. Конкретный выбор не подменяется другим качеством/озвучкой. Если вариант не найден, план продолжает ждать.
Управление ожиданием: «Загрузки → Будущие скачивания». Для изменения выбора удалить ожидающий план и добавить заново. При удалении записи уже переданного плана сама загрузка не удаляется.

Фоновые проверки JobScheduler запрашиваются с периодом 15 минут; Android вправе задерживать их из-за Doze/ограничений батареи/сети/запуска foreground service. При запрете фонового запуска план сохраняется и пробуется повторно. После force-stop или отключения приложения нужно открыть YORU снова. Настройка Wi-Fi учитывается; точное время скачивания не гарантировано.

Кэш не изменялся: RAM-кэша нет, storage/TTL/limits/decode исходной 4.17.2 сохранены. Изменение ImageLoader ограничено политикой переполнения его executor.
В плеере не создаётся WebView; просмотр эпизодов нативный. Пункты «Новые серии» и «Только встроенный просмотр» удалены из настроек. Фоновые уведомления прежнего механизма не отключались этим удалением UI.

## Сборка из ZIP

Требования: Java 17, Android SDK 36 / build tools 36.0.0, доступ к Google Maven/Maven Central/Gradle.

```sh
cd yoru-android
chmod +x gradlew
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Debug APK использует `.debug` applicationId. Для подписанного release нужен существующий ключ владельца; его нет в новом source ZIP. Репозиторный CI сохраняет прежний способ подписи для совместимости обновления. Не менять ключ автоматически и не публиковать его содержимое.
Workflow из ZIP ориентирован на этот репозиторий и существующий signing input; он не является автономной конфигурацией подписи. Сами исходники debug собираются без старых архивов/ключей. YURO Guard подключается только при наличии его каталога и не входит в этот ZIP.

## Проверки

```sh
python tools/check-yoru-update.py
python tools/package-yoru-source.py
git diff --check
sha256sum -c handoff/YORU-4.19.0-source.zip.sha256
```

Unit tests: перегрузка без исполнения на вызывающем потоке, освобождение отменённых заданий, отмена running/queued задач; точные номера/качество будущих скачиваний, запрет future/invalid episodes.
Перед установкой APK сверить `.sha256`, проверить подпись apksigner и ZIP integrity.

## Обязательная ручная регрессия

- Слабый телефон: быстрый скролл/смена вкладок; изображение, дата и действие не остаются от предыдущей recycled строки.
- Серии: будущая не играет, но планируется; вышедшая играет; повторная загрузка/пауза/возобновление/удаление; offset прокрутки сохраняется.
- План: исчезновение процесса, reboot, Wi-Fi/mobile, Doze, force-stop; недоступная озвучка или качество не подменяются; отмена ожидания; нет повторного downloadId.
- Плеер: быстрая смена серии и озвучки, закрытие во время resolver, PiP; текущий просмотр не переключается старым callback.
- HLS/DASH offline в авиарежиме; экспорт готовых файлов через проводник.

Эти сценарии на физическом устройстве в sandbox не выполнены; успешные unit tests и APK assembly не заменяют их.
