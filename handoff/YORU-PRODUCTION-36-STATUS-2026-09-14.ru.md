# YORU: реестр 36 требований production-обновления

База: **4.19.1 / code70**, ZIP SHA256 `6b76e9c171c747f72225c95324c8bd650e328b6e211379f31542d73032445f61`.

Статус на 14.09.2026: реализация начата на базе 4.19.1, рабочая версия **4.20.0-dev.1 / code71**. Это НЕ production-релиз. Добавлены изменения Java/UI/сети и тесты; Android-сборка и выполнение JUnit пока не подтверждены. Исходные критерии ниже сохраняются.

## Согласованные критерии приёмки

| № | Требование | Точка реализации / критерий |
|---|---|---|
| 1 | Оценка Shikimori вместо озвучки на карточке | `Ui.Card` + metadata по malId; не рейтинг произвольного провайдера под видом Shikimori. Существующий рисунок звезды не менять. Неизвестная оценка — без выдуманного числа |
| 2 | Топовая бесконечная главная по 6 и плавное обновление календаря | `MainActivity.home`, RecyclerView, `CalendarScreen`; добавлять 6 видимых карточек без полного пересоздания адаптера. Новая порция в конце ленты и pull-to-refresh — разные действия |
| 3 | Популярные озвучки и просмотры из Shikimori | Проверенная GraphQL-схема даёт fandubbers/fansubbers, но не просмотры по озвучкам. Нельзя выдумывать статистику. При отсутствии реальных данных — любимые пользователя и доступность серий, без ложной подписи «по просмотрам Shikimori» |
| 4 | Плеер под описанием, озвучка/сезон/серия | `DetailsActivity` + общий собственный Media3 player/controller. Не iframe и не отдельный плеер из чужого APK; корректное освобождение decoder/AudioFocus при смене экрана |
| 5 | Связь сезонов | chronology/related с Shikimori ID + source ID/season ID. Выбор тайтла четвёртого сезона не должен автоматически подменяться первым; спецвыпуски и фильмы не считать сезонами по одному номеру в названии |
| 6 | Ежедневная смена рекомендации | Детерминированный daily seed + валидные рейтинговые кандидаты. Не постоянно заданная «Фрирен»; не случайная смена при каждом повороте |
| 7 | Все жанры | Полный динамический справочник провайдера с его ID; пагинация/поиск жанров, а не короткий захардкоженный список |
| 8 | Убрать мигание кэшированных обложек | `Ui.Card.bind`/ImageLoader: не сбрасывать готовый drawable при том же ключе и не показывать системную иконку между привязками. Не добавлять RAM-кэш и не менять дисковые лимиты/ключи/очистку |
| 9 | Живая главная: топ, рекомендации, обновление | Блоки на прежней палитре, Shikimori metadata, ежедневный выбор и ручное обновление без прыжка скролла |
| 10 | Современный OkHttp, приоритет текущего экрана, быстрые серии | Общие клиенты/connection pool; миграция API, resolver, posters, metadata download, player datasource, update receiver, вспомогательных сетевых вызовов. Ограниченные очереди, отмена offscreen Call, защита скачиваний от голодания. Не безлимитные потоки и не logging interceptor. Официальный changelog: OkHttp 5.5.0; Maven/Gradle-сборка пока недоступна |
| 11 | Убрать YORU Quality+ | `QualityPlus` labels и все пользовательские подписи: 1440p · 2K, 2160p · 4K. Не приписывать 4K потоку 1080p |
| 12 | Плавный поиск с обложками | debounce + latest-query generation, отмена предыдущих запросов, локальные/сетевые предложения с постером и названием; частичные обновления |
| 13 | История поиска с обложками | Сохранять связанный Anime ID/poster при выборе результата. Обычной текстовой фразе не приписывать случайную обложку; история текста остаётся доступной |
| 14 | Автообновление каждый час без надписи о сохранённой подборке | foreground stale-while-refresh и pull, без очистки текущего списка. При закрытом приложении/Doze Android не гарантирует запуск ровно в указанную минуту |
| 15 | Красивый выбор коллекции | Контейнеры-кнопки со стилем YORU и заметным выбранным состоянием; рабочее добавление и пользовательские папки |
| 16 | Перенесённые даты в календаре | Повторная сверка по ID+episode, замена перенесённого события, удаление устаревшего, правильное разделение даты анонса и доступности видео |
| 17 | Быстрее resolver/перехват, только свой плеер | URL+headers+MIME, дедупликация, bounded timeout, реальный master manifest. Не копировать рекламные WebView interceptors из APK, не отключать TLS и не обходить DRM |
| 18 | 144p/240p только при наличии | Расширить model/parser/labels; меню текущего видео строить по реальным stream/track entries, не по общему списку настроек |
| 19 | Точный размер | HEAD Content-Length либо валидный Content-Range для конкретного ресурса. Для закрытого VOD HLS — только если известны размеры всех выбранных segments/init/audio и учтены byte ranges. Live/неизвестные длины — «неизвестен», не приблизительное число с подписью «точно» |
| 20 | Выбор папки системным проводником | ACTION_OPEN_DOCUMENT_TREE, persistable grant, проверка записи/отзыва доступа, потоковая запись через ContentResolver. SAF-провайдер может не поддерживать seek: обязателен последовательный fallback. HLS не выдавать за единственный MP4 |
| 21 | Иконка удаления в загрузках | Единый минималистичный vector/canvas icon, прежняя палитра, 48dp зона нажатия, подтверждение удаления |
| 22 | Обои, обрезка, предпросмотр вкладок, прозрачность | Системный picker/Google Photos provider при наличии; локальная копия выбранного изображения как пользовательские данные, не новый кэш. Отдельный редактор до сохранения, crop/scale, alpha-ползунок, cancel без изменения настроек. RGB-палитру не менять |
| 23 | МСК/локальное время | Парсить ISO-offset исходного timestamp, затем Europe/Moscow или системную зону. Нельзя просто дописать МСК к произвольному UTC/local времени; группировку дней календаря считать в выбранной зоне |
| 24 | Настройка «Разрешение» | Удалить Quality+ из подписи, сохранить значение/совместимость сохранённых настроек |
| 25 | Жанр карточки открывает отфильтрованный каталог | Передавать ID жанра и источник, не только строку перевода; unknown ID не подменять жанром другого сервиса |
| 26 | Жесты, замок, снимок кадра | Стабильный gain для яркости/громкости, визуальный индикатор, lock с отдельным unlock. PixelCopy именно video surface для незашифрованного разрешённого кадра; отказ защищённого видео не обходить |
| 27 | Заголовок «Рекомендации» | Удалить прежнюю фразу во всех состояниях главной |
| 28 | Высококачественные постеры / экономия трафика | Оригинальный URL по умолчанию, без собственного перекодирования байтов; low-quality URL только по настройке. Декодирование не должно приводить к OOM. Не менять cache budget и не очищать пользовательский кэш |
| 29 | Согласовать число серий | Отдельно metadata total, aired, доступные у озвучки. Не max() по всем провайдерам, не механически превращать 24 доступных в 36 всего; учитывать незавершённые данные/спецвыпуски |
| 30 | Этти/хентай и остальные жанры | Не скрывать названия жанров из полного справочника. Различать жанр и возрастной рейтинг; существующий !rx в Shikimori-запросах требует явного пересмотра для соответствующего выбранного фильтра |
| 31 | Убрать поясняющую фразу поиска | Удалить точный текст без удаления поля/состояний ошибок |
| 32 | Крестик вместо «Отменить» у фильтров | Close icon сверху справа, закрытие без применения, Back/outside с тем же результатом |
| 33 | Минималистичная иконка настроек | Изменить только geometry нужной иконки; звезду и палитру не менять |
| 34 | Убрать верхнюю «Историю» | Удалить действие в правом углу каталога/уточнить экран по текущей реализации, саму историю и её данные сохранить |
| 35 | Убрать полоску прогресса карточки | Скрыть/удалить только presentation view; запись позиции и «продолжить» должны остаться |
| 36 | SDK37 | Официальная документация Android 17 подтверждает compile/target37. Проверить совместимость AGP/Gradle, system back, MediaSession/FGS, CT, большие экраны, SAF и screenshots. Не просто поменять число без сборки |

## Последовательность после устранения блокера

1. Независимые модели/правила качества, сезонов, размера, часового пояса и свежести + unit-тесты.
2. Сетевая миграция и cancellation с сохранением cache/storage/signature контракта.
3. Нативная главная/каталог/жанры/коллекции/расписание.
4. Общий собственный плеер под описанием, SAF и кадры.
5. Обои/редактор/прозрачность без изменения цветов.
6. SDK37, сборка release+debug, source ZIP, smoke/regression. Закрыть каждую строку только с реальным evidence.

APK/исходник 4.19.1 не перезаписывать. Прежний отдельный YORU VK и подтверждённый просмотр ссылок в нём не трогать.
