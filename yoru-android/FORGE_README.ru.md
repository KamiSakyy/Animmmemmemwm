# YORU Forge

YORU Forge — отдельное Android-приложение для редактирования исходников YORU с телефона и запуска release-сборки APK через GitHub Actions.

## Версия 0.1.0

Что уже есть:

- выбор папки проекта через системный проводник Android;
- постоянный доступ к выбранной папке через Storage Access Framework;
- список текстовых файлов проекта;
- встроенный редактор `.java`, `.gradle`, `.xml`, `.json`, `.md`, `.properties`, `.yml` и других текстовых файлов;
- сохранение изменений обратно в выбранную папку;
- экспорт исходников в `.zip` без `.git`, `build`, APK, архивов и signing-файлов;
- быстрые кнопки открытия GitHub Actions для сборки YORU и самого Forge;
- ссылка на папку готовых APK.

## Почему не сразу полностью офлайн

Полностью офлайн-сборка APK на Android требует JDK, Gradle, Android SDK, build-tools, подписи APK, кешей Maven/Google и нормального вывода ошибок. Это возможно, но приложение получится тяжёлым.

Первый стабильный путь — редактирование на телефоне и release-сборка через GitHub Actions. Так APK собирается в той же среде, где уже успешно собирался YORU.

## GitHub Actions

Для публичного репозитория стандартные GitHub-hosted runners обычно доступны бесплатно. Для приватного репозитория есть месячные лимиты минут и storage по тарифу аккаунта. Если лимит закончится, сборку можно будет сделать локально на компьютере или позже добавить self-hosted/Termux режим.

## Следующие этапы Forge

- поиск по файлам;
- создание новых файлов;
- подсветка Java/XML/Gradle;
- встроенный просмотр ошибок Gradle;
- безопасное подключение GitHub на устройстве без хранения токенов в исходниках;
- запуск workflow в один тап;
- скачивание последнего APK прямо из Forge;
- экспериментальный локальный SDK/JDK режим для офлайн-сборки.
