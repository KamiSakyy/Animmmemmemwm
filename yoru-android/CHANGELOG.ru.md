# YORU 2.7.0 — полный MP4 экспорт и мощная распаковка VPN подписок

- Исправлен критичный экспорт одиночных MP4/MKV/WebM: YORU теперь собирает файл из реальных `SimpleCache` spans, сверяет размер с фактически скачанными байтами и не отдаёт во внешние приложения маленький манифест/объект вместо видео.
- Сохранение в Android/Google проводник, галерею и отправка теперь проверяют количество скопированных байт; неполный файл удаляется или отклоняется с понятной ошибкой.
- Автоматический HLS/DASH → MP4 экспорт стал строже: крошечный повреждённый результат больше не считается готовым MP4.
- VPN импорт усилен под форматы реальных клиентов: plain links, base64/base64url подписки, JSON/sing-box/Xray, Clash JSON/YAML и ссылки внутри вложенных строк.
- Поддержаны профили `vless://`, `vmess://`, `trojan://`, `ss://`, `socks://`, включая вложенные поля TLS, Reality, WS, gRPC, Clash `ws-opts` и sing-box `transport`.
- Загрузка subscription URL пробует User-Agent популярных VPN-клиентов, варианты `format/type`, HTTP fallback и мягкий TLS fallback, если сервер рвёт стандартное соединение.
- Версия Android-пакета поднята до `versionName 2.7.0`, `versionCode 14`.

# YORU 2.6.0 — видимый VPN, проводник на карточке и полный экран

- VPN вынесен в отдельную нижнюю вкладку `VPN`: поле подписки видно сразу на экране, рядом кнопка обновления локаций, список серверов, режим работы и кнопка подключения.
- Кнопка `Проводник` добавлена прямо на карточку готовой загрузки: файл сохраняется через системный Android-проводник в выбранную папку.
- Автоматическая MP4-сборка ограничена одним фоновым заданием и не стартует во время открытого плеера, чтобы не греть телефон пачкой конвертаций.
- Полный экран плеера теперь реально убирает интерфейс YORU и переносит видео на весь экран с immersive-навигацией.
- Плеер освобождает удержание экрана при паузе, если он не находится в полноэкранном режиме.
- Версия Android-пакета поднята до `versionName 2.6.0`, `versionCode 13`.

# YORU 2.5.0 — системный проводник для MP4 и встроенный VPN

- Добавлено сохранение готового видео через системный Android-проводник: пользователь выбирает любую папку, YORU копирует туда MP4/MKV/WebM без передачи `content://` во внешний плеер.
- Открытие во внешнем плеере теперь передаёт точный MIME готового файла, а не только общий `video/*`.
- Добавлен экран встроенного VPN: вставка subscription URL, загрузка и распаковка локаций `vless://`, `vmess://`, `trojan://`, `ss://`, `socks://`.
- Добавлен системный `VpnService`, запрос Android VPN-разрешения, режимы маршрутизации `только YORU`, `выбранные приложения`, `все приложения`.
- В сборке APK через GitHub Actions подключается Xray-core AAR из V2RayEZ, без сохранения приватных subscription URL в репозитории.
- Добавлен `AGENTS.md` с инструкцией для будущих сессий: как работать с проектом и как собирать APK.
- Версия Android-пакета поднята до `versionName 2.5.0`, `versionCode 12`.

# YORU 2.4.0 — автоматический MP4 и внешние плееры как в Telegram

- Исправлено открытие готовых MP4 во внешних видеоплеерах: `FileProvider` теперь отдаёт и автоматически собранные MP4, а не только быстрые копии обычных файлов.
- Открытие внешнего плеера сделано через стандартный Android `ACTION_VIEW` с MIME `video/*`, `ClipData` и выдачей read-доступа всем подходящим приложениям.

- Старые уже скачанные HLS/DASH серии тоже запускают автосборку MP4 при открытии раздела загрузок.
- Если MP4 ещё собирается, повторное нажатие больше не запускает второй тяжёлый процесс, а сообщает, что сборка уже идёт.
- Удалён источник SovetRomantica из каталога, плеера и активных списков.
- Kodik 2026 оставлен.
- Версия Android-пакета поднята до `versionName 2.4.0`, `versionCode 11`.

# YORU 2.1.2 — скачивание текущего iframe и уведомления

- Добавлена кнопка «Скачать эту серию» прямо в карточку выбора серии на экране плеера.
- Из плеера больше не нужно вручную вводить номер серии: скачивается текущая выбранная серия.
- В карточке аниме ручной ввод заменён на красивый выбор серии из списка.
- Для YummyAnime iframe добавлен принудительный режим подготовки загрузки: сначала берётся текущий iframe и реальные видеозапросы, которые WebView увидел во время воспроизведения.

- Если iframe ещё не отдал поток, загрузка текущей серии дополнительно пробует обычный resolver и общий пул всех источников.
- Общий пул скачивания сохранён: YummyAnime, AniLiberty, AnimeVost, AniLib, AniMedia, Kodik 2026, SovetRomantica, direct Kodik и распознанные iframe-плееры.
- Retry загрузки продолжает заново искать варианты по всем источникам.
- Уведомления о новых сериях усилены: после добавления в коллекцию проверка запускается сразу, а не только по расписанию.
- В профиле добавлена кнопка «Проверить избранное сейчас».
- Периодическая проверка избранного каждые 6 часов и запуск после перезагрузки устройства сохранены.
- Версия Android-пакета поднята до `versionName 2.1.2`, `versionCode 6`.

# YORU 2.1.1 — все источники в плеере и скачивании

- Возвращена категория «Все источники» с объединённой выдачей по рабочим каталогам.
- В плеер возвращён явный выбор источника: Все источники, YummyAnime, AniLiberty, AnimeVost, AniLib и AniMedia.
- Удалены AniList и SameBand из каталога и экранов выбора источника.
- AnimeGO больше не используется как активный источник.
- Онлайн-просмотр теперь выбирает нативный HLS/DASH/MP4 для AniLiberty, AnimeVost, AniMedia, AniLib и а YummyAnime продолжает открываться через iframe.
- Скачивание больше не останавливается на первом найденном источнике: приложение собирает общий пул прямых потоков из текущего плеера, родного источника, YummyAnime, AniLiberty, AnimeVost, AniLib, AniMedia, Kodik 2026, SovetRomantica и прямого Kodik, если он доступен.
- Перед скачиванием показываются все найденные озвучки, студии, плееры и качества; варианты дедуплицируются без скрытого ограничения на один источник.
- Подготовка direct HLS/DASH стала мягче: если master-manifest временно не раскрывается, но URL сам является видеопотоком, он остаётся кандидатом для Media3.
- Retry не привязан к старому одиночному источнику: приложение заново строит общий пул вариантов и подбирает совпадающий источник/озвучку/качество либо ближайший доступный вариант.
- В загрузках сохраняется выбранная озвучка, студия и качество, чтобы разные версии одной серии не конфликтовали.
- Для тайтлов в коллекции добавлена периодическая проверка новых серий и уведомление Android при появлении обновления.
- Обновлены подписи источников, сетевые заголовки плеера и лимиты кэша Media3.

Проверены открытые проекты 2026: Vetro, YummyTV, YummyDroid, animevost-mobile, Dream Cast и несколько aniyomi/fork-extensions. JutSu не добавлен как активный источник, потому что актуальная реализация Vetro подтверждает переход сайта на player-разметку с заглушками вместо прямых видео. Dream Cast не добавлен, потому что live endpoint `dreamerscast.com` из окружения не подтвердился. Источники без проверки доступности и источники с API-ключами не включались.

Доступность каталогов, озвучек и прямых потоков по-прежнему зависит от самих сайтов, региона и текущих ограничений плееров.
