# YORU Android Java 4.12.0

YORU — стабильное Java-приложение `app.yoru.mobile` для поиска, карточек, просмотра, загрузок, коллекции и уведомлений о новых сериях. Текущий активный продукт — Java. Kotlin-модуль удалён из Gradle и из исходников ветки.

## Главное в 4.12.0

- Карточки показывают статус тайтла (`Онгоинг`, `Закончен`, `Анонс`) и прогресс выхода: `Вышло X из Y`.
- YORU сохраняет отдельные поля `episodesTotal`, `episodesAired` и `nextEpisodeAt`, поэтому детали/кэш/загрузки не теряют расписание.
- Для онгоингов экран тайтла подтягивает индивидуальную дату следующей серии через Shikimori `nextEpisodeAt`, когда есть MAL/Shikimori ID.
- Серии, которые ещё не вышли, теперь выглядят как заглушки с датой, без обычной обложки, play-действия и скачивания.
- Если выбрана AniLibria.TV или другая озвучка, но у конкретной серии её нет, YORU автоматически показывает доступные реальные озвучки из скрытых источников и не падает в “серия недоступна”.
- Скрытый discovery оставляет выбранную озвучку первой для скорости, но при отсутствии голоса расширяет поиск по маршрутам под капотом.
- Технические route-бренды `YORU Prime/Reserve/Max`, Yummy, Kodik, Anix/Sekai больше не показываются как озвучки или пользовательские источники.
- Gradle остаётся Java-only: активный модуль только `:app`, версия `4.12.0` / `43`.

## Сборка

```bash
cd yoru-android
./gradlew --no-daemon :app:assembleRelease
```

Готовый файл локально:

```text
yoru-android/app/build/outputs/apk/release/app-release.apk
```

В Arena-песочнице локального JDK может не быть. Ветка содержит workflow `.github/workflows/build-apk.yml`, который собирает release APK на GitHub Actions.

## Правила продолжения

- Не возвращать Kotlin без прямой команды пользователя.
- Не возвращать Clips, “Ещё”, AniList как пользовательский источник, TSM, AnimeGO, JutSu, SameBand, SovetRomantica, Yummy Legacy.
- Не добавлять VPN/VLESS/Xray/proxy/private token и MP4-конвертацию.
- “Озвучка” — только реальная команда перевода/дубляжа: AniDUB, AniLibria.TV, AniMaunt, AnimeVost, AniStar & DEEP, Beyond:Studio, Dream Cast, AniMedia и т.п.
- Скрытые маршруты можно использовать только под капотом и нельзя показывать их как озвучки.
