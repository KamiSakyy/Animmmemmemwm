# YORU Android Java 4.15.0

YORU — стабильное Java-приложение `app.yoru.mobile` для поиска, карточек, просмотра, загрузок, коллекции и уведомлений о новых сериях. Текущий активный продукт — Java. Kotlin-модуль удалён из Gradle и из активных исходников ветки.

## Главное в 4.15.0

- Масштабная оптимизация скорости без изменения auto-mode: пользователь выбирает озвучки, скрытые маршруты остаются внутренними.
- Каталог показывает локальные карточки мгновенно и обновляется без пустого `Загружаем…`.
- Карточка тайтла параллельно грузит метаданные и серии, поэтому список серий появляется быстрее.
- ImageLoader показывает оригинальное качество без RGB_565/downsample, с большим memory cache и inBitmap reuse.
- Календарь cache-first, WAL для SQLite, фоновый hourly trim, throttled progress-save в плеере и более точный счётчик трафика.
- Убраны лишние технические тексты и настройки: `Подробнее`, ручная проверка избранного, `Мини-режим`, `Не сохранять новую историю`, `Данные и чистка`.

- Auto-mode сохранён: YORU подбирает просмотр по озвучкам во всей скрытом просмотре, а не заставляет пользователя выбирать сайт или сервер.
- UI очищен от пользовательских технических лейблов: карточки и детали говорят про YORU, озвучки, дорожки, Quality+ и прогресс.
- Карточки стали богаче без новых кнопок: статус, прогресс просмотра, коллекция/онгоинг/вышедшие серии и чип любимых озвучек.
- Главная стала чище: “Сейчас в YORU”, продолжение просмотра и “Новые серии для вас” из коллекции без перегруза кнопками.
- YORU Quality+ сохраняет 1440p/2160p в настройках, карточке, плеере и скачивании — только как выбор реального исходного потока, без фейкового апскейла.
- Любимые озвучки хранятся как список приоритета: выбранные дорожки поднимаются в карточке, плеере, скачивании и сортировке скрытого просмотра; строгий режим “только выбранная” сохранён отдельно.
- Расширенная карточка показывает расширенные данные: студию, страну, премьеру, длительность, количество переводов, рейтинги, ID, франшизу, медиа, папки и любимые озвучки.
- Коллекция получила пользовательские папки/полки поверх старых статусов `В планах`, `Смотрю`, `Просмотрено`, `Отложено`, `Брошено`.
- Animetka подключена глубже через публичный `/api/anime/playlist` и общий каталог; новые качества появляются только если manifest реально отдаёт соответствующий URL.
- Календарь в режиме `Все` сохраняет виртуализацию порциями: сначала 5 событий, затем следующие 5 при прокрутке вниз или кнопкой `Ещё 5`.
- Добавлены плавные вставки событий, footer `показано X из Y`, быстрый переход `К ближайшей`, счётчики на фильтрах и днях.
- Кэш календаря читается в фоне, personal buckets (`Избранное`, `Новые`) обновляются после фонового прогрева `SecureStore`, без блокировки UI.
- Дубликаты расписания схлопываются, favorite/history внутри buckets мемоизируются, counters больше не пересчитываются сортировкой.
- Карточки календаря получили цветовые акценты, accessibility descriptions, long-press добавление в коллекцию и полезный empty-state.
- Сохранены улучшения 4.12.10/4.12.9: быстрый cold start, bounded executors/cache, меньшие timeout'ы, image dedupe, фоновые уведомления JobScheduler + AlarmManager.


- Календарь переделан в один полноэкранный `RecyclerView`: шапка, дни, фильтры и события прокручиваются вместе, без вложенного списка, который мог показывать только 2 карточки.
- По умолчанию календарь показывает весь поток событий за 28 дней в режиме `Все`; отдельные дни — только ручные фильтры после нажатия.
- Расписание расширено: больше страниц ongoing/anons, fallback до 120 тайтлов и аккуратные слоты `Скоро` для тайтлов без точной даты.
- Видимые системные полосы прокрутки скрыты в основных экранах и диалогах.
- Главная восстановлена с красивым anime hero/poster и без технического текста про изменения приложения.
- Загрузки показывают крупные preview/poster-карточки для скачанных эпизодов.
- Нижняя навигация сохраняет кнопку строго `Календарь` без цифр/бейджей.
- Стартовый loading/shell экран не используется.
- Java-only сборка сохранена: активный модуль только `:app`, версия `4.15.0` / `57`.

## Сборка

```bash
cd yoru-android
./gradlew --no-daemon :app:assembleRelease
```

Готовый файл локально:

```text
yoru-android/app/build/outputs/apk/release/app-release.apk
```

В Arena-песочнице локального JDK может не быть. Ветка содержит workflow `.github/workflows/build-apk.yml`, который собирает release APK на GitHub Actions.

## Правила продолжения

- Не возвращать Kotlin без прямой команды пользователя.
- Не возвращать Clips, “Ещё”, AniList как пользовательский источник, TSM, AnimeGO, JutSu, SameBand, SovetRomantica, Yummy Legacy.
- Не добавлять VPN/VLESS/Xray/proxy/private token и MP4-конвертацию.
- Не возвращать стартовый loading/shell экран, технические startup-тексты и бейджи в `Календарь`.
- Календарь по умолчанию должен показывать все дни; в режиме `Все` список остаётся быстрым и не урезается.
- “Озвучка” — только реальная команда перевода/дубляжа: AniDUB, AniLibria.TV, AniMaunt, AnimeVost, AniStar & DEEP, Beyond:Studio, Dream Cast, AniMedia и т.п.
- Скрытые маршруты можно использовать только под капотом и нельзя показывать их как озвучки.
- Выбранная озвучка — быстрый приоритет, но при её отсутствии YORU обязан скрыто найти рабочую реальную озвучку/маршрут.
- Future-серии не должны выглядеть playable: без обычной обложки, play и download.
- Cache должен оставаться bounded: TTL, лимиты, trim.
