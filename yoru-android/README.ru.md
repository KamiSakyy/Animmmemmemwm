# YORU для Android

Нативное Android-приложение на Java, Android SDK и Gradle для просмотра аниме: каталог, поиск, карточки, коллекция, история, загрузки и настройки сделаны стандартными Android Views. Онлайн-видео открывается сразу: прямые потоки идут через Media3 ExoPlayer, YummyAnime iframe запускается без ожидания resolver, а извлечение прямого потока выполняется фоном.

## Требования

- Android 8.0 / API 26 и новее.
- Интернет для актуального каталога, просмотра и проверки новых серий.
- Актуальный Android System WebView для внешних iframe-плееров.
- Разрешение на уведомления на Android 13+ для фоновых загрузок и сообщений о новых сериях.

## Что включено

- Каталоги: Все источники, YummyAnime, AniLiberty, AnimeVost, AniLib, AniMedia, Kodik 2026, Shikimori.
- AniList и SameBand убраны из приложения.
- В плеере доступен выбор «Все источники» или конкретного источника: YummyAnime, AniLiberty, AnimeVost, AniLib, AniMedia, Kodik 2026.
- YummyAnime Iframe для серий, озвучек и студий, которые доступны только через внешний плеер.
- Нативный плеер Media3 для прямых MP4/HLS/DASH-потоков AniLiberty, AnimeVost, AniMedia и распознанных iframe-вариантов; для YummyAnime iframe при удачном извлечении отображается `НАШ МОЩНЫЙ ПЛЕЕР`.
- Принудительная подготовка скачивания из текущего YummyAnime iframe: resolver ловит Kodik, CVH/CdnVideoHub и реальные `.m3u8`, `.mpd`, `.mp4`, `.mkv`, `.webm` запросы во время воспроизведения без тяжёлых фоновых probe-задач.
- Скачанные MP4/MKV/WebM серии можно открыть во внешнем плеере через стандартный Android выбор приложений, отправить через “Поделиться”, сохранить в `Видео / YORU` или сохранить через системный проводник Android в любую папку; кнопка `Проводник` находится прямо на карточке загрузки; HLS/DASH-загрузки автоматически собираются в MP4 через Media3 Transformer сразу после скачивания.
- Офлайн-раздел показывает быстрые действия `YORU`, `Проводник`, `Плеер/MP4`, `Удалить`, статус, формат и размер скачанной серии.
- Массовое скачивание из карточки аниме: следующие 3, 6, 12 серий или выбор нескольких серий из списка, затем общее качество.
- Скачивание собирает общий пул из текущего плеера, родного источника, YummyAnime, AniLiberty, AnimeVost, AniLib, AniMedia и Kodik 2026, если источники отдают доступный поток без пользовательских API-ключей.
- Подбор прямых потоков для загрузки из Kodik, Alloha, Aksor, Sibnet, VK, Aniboom и AniLib, если плеер отдаёт доступный адрес.
- В карточке аниме скачивание выбирает серию из списка, а в плеере скачивает текущую серию без ручного ввода номера.
- Выбор серий, озвучек, студий, плееров и качества на экране просмотра и перед скачиванием.
- Коллекция со статусами, история просмотра, продолжение прямого видео и офлайн-просмотр завершённых загрузок.
- Уведомления о новых сериях для тайтлов в коллекции: проверка после добавления в избранное, ручная проверка в профиле, периодическая проверка после запуска приложения и после перезагрузки устройства.
- Встроенный VPN вынесен в отдельную нижнюю вкладку `VPN`: пользователь вставляет subscription URL прямо на экране, YORU распаковывает локации и запускает системный VPN-режим через Android `VpnService`; доступны режимы только для YORU, выбранные приложения или все приложения.
- Импорт веб-коллекций YORU v1–v5 и коллекций приложения. Новые экспорты используют формат yoru.android.v2.

Доступность видео, реклама и ограничения региона определяются источниками. Аниме-источники без VPN не обходят авторизацию, проверки браузера или ограничения правообладателей. Если внешний плеер не отдаёт прямой поток, приложение показывает онлайн-вариант и не создаёт пустую загрузку.

## Офлайн и сеть

Раздел «Загрузки» показывает состояние сохранения. Офлайн-просмотр разрешён только для завершённых загрузок. Их данные находятся в приватном внутреннем каталоге приложения, отдельно от временного кэша. Очистка кэша не удаляет сохранённые серии.

По умолчанию загрузки ожидают Wi-Fi / безлимитную сеть. Переключатель находится в профиле. Для фоновых загрузок используется видимое уведомление; Android 13+ может запросить разрешение на уведомления. Поведение фоновой работы также зависит от ограничений Android и производителя устройства.

Счётчик трафика начинается после установки обновления / сброса. Разделение по типу сети является оценкой; при VPN и неотслеживаемых сменах сети часть расхода учитывается как «другой». Дополнительный доступ к статистике остальных приложений не запрашивается.

## YORU 2.8.0

- Аварийный hotfix VPN: вкладки `VPN` и `Загрузки` защищены от вылетов из-за старых или повреждённых локальных записей.
- VLESS добавлен как полноценный профиль Xray, включая Reality/TLS/WS/gRPC/H2/XHTTP/HTTPUpgrade и flow.
- Перед запуском системного VPN приложение сначала обновляет и распаковывает подписку через обычную сеть телефона, не через уже активный VPN-туннель.
- Локации показывают страну/флаг, если это можно определить из имени сервера, кода страны или emoji-флага.

## YORU 2.7.0

- Полный MP4 экспорт: одиночные видео копируются из реальных Media3 cache spans и проверяются по размеру перед внешним плеером, отправкой, галереей и системным проводником.
- Неполный или маленький файл больше не передаётся наружу: результат удаляется/отклоняется и показывается ошибка.
- VPN подписки распаковываются в стиле современных клиентов: plain list, base64/base64url, sing-box/Xray JSON, Clash JSON/YAML, вложенные ссылки и профили VLESS/VMess/Trojan/Shadowsocks/SOCKS.

## Сборка

Откройте эту папку в Android Studio либо используйте Gradle Wrapper.

1. Установите JDK 17 или новее.
2. Установите Android SDK Platform 36.
3. Укажите путь SDK в `local.properties` (`sdk.dir=...`) или в `ANDROID_HOME`.
4. Сохраните приватную папку `owner-signing/` рядом с проектом, если собираете релиз с прежней подписью.
5. Выполните:

```sh
./gradlew --no-daemon :app:assembleRelease
```

Windows:

```bat
gradlew.bat --no-daemon :app:assembleRelease
```

Результат: `app/build/outputs/apk/release/app-release.apk`.

Проект использует Android Gradle Plugin 8.13.2, Gradle 8.13, Media3 ExoPlayer и jsoup. Приложение не требует собственного сервера и не включает весь сайт в WebView.

## Структура

- `app/src/main/java/app/yoru/mobile/` — код приложения.
- `ApiRepository.java` — публичные источники, сопоставление тайтлов, серии и варианты загрузки.
- `VideoResolver.java` — распознавание прямых потоков из iframe-плееров, включая Kodik 2026 и CVH/CdnVideoHub.
- `EpisodeUpdateReceiver.java` — проверка новых серий и уведомления.
- `MainActivity.java` — главная, каталог, коллекция и источники.
- `DetailsActivity.java` — описание и связанные истории.
- `PlayerActivity.java` — нативный проигрыватель и внешние плееры.
- `OfflineExporter.java` — экспорт скачанных MP4/MKV/WebM во внешние плееры, системный проводник и `Видео / YORU`.
- `DownloadHub.java` — очередь загрузок Media3 и офлайн-воспроизведение.
- `SecureStore.java` — локальные данные, шифруемые ключом Android Keystore.
- `YoruVpn*.java` — встроенный VPN: подписка, локации, Xray JSON, Android `VpnService` и запуск core.
- `AppSecurity.java` — проверка релизной подписи.
- `app/src/main/assets/` — стартовая подборка и обложки для начального/офлайн-экрана.
- `owner-signing/` — приватные материалы подписи владельца.
- `SECURITY.ru.md` — модель защиты и её ограничения.

## Обновления

Для обновления установленного приложения нужна та же подпись. Сохраняйте ключ из `owner-signing/`. При замене ключа обновите отпечаток `certificate-sha256.txt`; приложения, подписанные разными ключами, нельзя установить друг поверх друга без удаления прежнего.

Увеличивайте `versionCode` в `app/build.gradle` при выпуске новых APK.

## Важно владельцу

Не публикуйте архив исходников целиком в открытом репозитории, если в нём остаётся `owner-signing/`. Перед публикацией кода удалите приватные материалы подписи и любые локальные настройки. Этот README предназначен владельцу проекта.
