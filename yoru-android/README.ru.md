# YORU для Android

YORU — минималистичное Android-приложение для просмотра аниме: каталог, поиск, карточки, календарь выхода серий, коллекция, история, загрузки, настройки внешнего вида, приватные функции и удобный встроенный плеер. Внутренние детали работы не показываются пользователю: приложение само подбирает подходящий вариант просмотра и аккуратно восстанавливается при временных сбоях источников.

## Требования

- Android 8.0 и новее.
- Интернет для актуального каталога, просмотра и проверки новых серий.
- Разрешение на уведомления на Android 13+ для фоновых загрузок и сообщений о новых сериях.

## Что включено

- Каталоги: Все источники, YORU Source, YummyAnime, AniLiberty, AnimeVost, AniLib, AniLib Ultra, AniMedia, Animetka, AniDub, Kodik 2026, Shikimori.
- Быстрый поиск с историей запросов, очисткой истории, локальными совпадениями, жанрами, заметками, тегами и умными фильтрами.
- Отдельный календарь выхода серий: ближайшие онгоинги, премьеры, countdown, дни недели, фильтры и быстрый переход в карточку.
- YORU Source автоматически подбирает удобный вариант просмотра и не заставляет пользователя разбираться в технических деталях.
- Минималистичный видеоплеер: fullscreen, PiP, пауза/продолжить, −10/+10, масштаб, пропуск начала и управление поверх видео компактными иконками.
- Скачивание серий рядом со списком серий, массовая очередь, пауза/продолжение всех загрузок, повтор ошибок и просмотр офлайн прямо в YORU.
- Коллекция со статусами, история просмотра, план просмотра, заметки, теги, личные оценки, закрепления, пересмотры и скрытые тайтлы.
- Уведомления о новых сериях для тайтлов в коллекции, тихие часы и постеры в уведомлениях, когда они доступны.
- Настройки приватности и комфорта: приватный режим, безопасный режим, режим без спойлеров, скрытие просмотренного, оригинальные названия, мини-режим интерфейса, таймер сна и дневная цель.
- Импорт и экспорт коллекции, выбор собственного `.ttf/.otf` шрифта через системный проводник.

Доступность видео, реклама и ограничения региона определяются источниками. YORU не обходит авторизацию, проверки браузера или ограничения правообладателей.

## Офлайн и сеть

Раздел «Загрузки» показывает состояние сохранения. Офлайн-просмотр разрешён только для завершённых загрузок. Их данные находятся в приватном внутреннем каталоге приложения, отдельно от временного кэша. Очистка кэша не удаляет сохранённые серии.

По умолчанию загрузки ожидают Wi-Fi / безлимитную сеть. Переключатель находится в профиле. Для фоновых загрузок используется видимое уведомление; Android 13+ может запросить разрешение на уведомления.
