# YORU future agent guide

Работай только в текущей ветке Arena и не переключайся на другие ветки.

## Действующий порядок — 14 сентября 2026

Эти правила имеют приоритет над историческими разделами ниже.

- Делать полное согласованное обновление в исходниках одним связанным блоком. НЕ выпускать промежуточные APK и НЕ завершать работу на одной мелкой правке с просьбой продолжить.
- Не повышать версию, не собирать/публиковать APK до завершения интеграции. Автоматические workflows отключены; не обходить запрет через ручной запуск. Итоговая поставка — одна пара APK и соответствующего source ZIP через GitHub Releases.
- Не запускать smoke/unit/device/provider/SDK-пробы. Последние исходники не скомпилированы; прежняя сборка dev.11 не подтверждает новые изменения.
- Рабочая основа — подтверждённая пользователем dev.9 плюс изменения dev.10 и последующая интеграция. Не откатывать к 4.17.2 или к неподтверждённым dev.3–8.
- Не менять палитру, существующую звезду рейтинга, кэш/его лимиты/алгоритмы. Не добавлять RAM-кэш. Не включать минификацию, resource shrink и ZIP-сжатие APK.
- Не выдавать отсутствие данных Shikimori по просмотрам озвучек, неизвестный размер адаптивного видео или сборку SDK36 за выполнение соответствующих требований.
- Старый раздел APK workflow ниже — история, не инструкция к запуску сейчас.

## Главные правила продукта

- Отвечай пользователю по-русски и показывай этапы/проценты, когда задача долгая.
- Код Java/Kotlin/Groovy/XML должен быть чистым, без комментариев в коде и без намёков на ИИ.
- Не добавляй источники, которые требуют API-ключей.
- Не добавляй прокси для аниме-источников.
- Не возвращай AniList, SameBand, AnimeGO и SovetRomantica.
- Сохраняй быстрый режим `Все источники`; сомнительные источники не должны блокировать общий каталог.
- Kodik 2026 оставлен как рабочий источник.
- Просмотр только в нативном видеоплеере YORU. Не возвращать iframe/WebView-просмотр или выбор внешнего плеера.
- Resolver получает поток для нативного плеера; iframe не использовать.
- Для скачанного HLS/DASH не запускать пересборку/конвертацию в отдельный файл; офлайн-поток открывается во встроенном плеере YORU.
- Если внешний плеер не принимает `content://`, пользователь должен иметь действие сохранения через системный проводник Android.

## APK workflow

Основная сборка APK делается GitHub Actions workflow `.github/workflows/build-apk.yml`.

Обычный порядок:

1. Проверить `git status --short --branch`.
2. Внести Android-правки.
3. Запустить локальные smoke checks:
   - Java parse через `/tmp/javaparse/bin/python` и `javalang`, если venv уже есть.
   - XML parse через `xml.etree.ElementTree`.
   - `git diff --check`.
4. Поднять `versionName`, `versionCode`, workflow filenames, README/CHANGELOG.
5. Закоммитить исходники.
6. `git push origin arena/01a0828d-animmmemmemwm`.
7. Ждать `gh run watch <run_id> --exit-status`.
8. После success сделать `git pull --ff-only origin arena/01a0828d-animmmemmemwm`.
9. Проверить `sha256sum -c apk-output/YORU-<version>-*.sha256` и `unzip -t` для APK.
10. Открыть release APK через `present_file`.
11. В финальном ответе дать ссылки на repo commit, release APK, debug APK и Actions.

## Сквозная интеграция выбора, загрузок и обновления экранов

Ручная озвучка сохраняется для конкретного аниме в существующих зашифрованных настройках: ключ источника и подтверждённые внешние идентификаторы, без объединения по похожему названию. Это постоянная пользовательская настройка, не новый кэш. Единый выбор используют Details, inline/fullscreen, поиск потоков, обычные и будущие скачивания. Отсутствующая выбранная озвучка не превращается молча в «Авто» при открытии диалога. Импорт/экспорт настроек поддерживает эти выборы. Разрешение скачивания, включая «Лучшее доступное», сохраняется отдельно и не сбрасывает разрешение просмотра.

ApiRepository/DownloadActions ищут точный эпизод, а не ближайший. Строгая озвучка больше не запускает скрытый поиск других озвучек. Общий фильтр загрузок отбрасывает другой тайтл, будущую/не ту серию и противоречащие параметры. Повтор загрузки не выбирает другое качество/озвучку. DownloadTracks задаёт ограничения выбора и сверяет выбранные видеодорожки adaptive-манифеста до постановки обычного/будущего скачивания: вместо аудио-only или более низкого разрешения под подписью выбранного возвращается отказ. Progressive с нулём периодов сохраняет существующую семантику URL; неизвестные размеры не выдумываются. Общие EpisodeRules учитывают и исходный Shikimori ID, ограничивают подтверждённый total при постановке загрузок и сохраняют устаревший будущий план без подмены выпуска.

Главная: ручной pull отменяет предыдущую подгрузку/тихое обновление; индикатор не зависает от конкурирующей операции. Каталог немедленно отменяет предыдущий поиск при вводе, после возврата продолжает нужный запрос с первой страницы, не показывает локальные подсказки как найденные сетевые результаты при пустом ответе. Тихое обновление не застревает после отмены и учитывает исчезновение дальнейших страниц. Календарь не показывает минутный отсчёт/«уже вышло» для даты без подтверждённого времени; премьера сама по себе не считается точным временем.

Ui.Progress снимает lifecycle listener при закрытии и отменяет связанную задачу при остановке/уничтожении владельца. Inline не сохраняет нулевую позицию до готовности видео; при смене озвучки сохраняет позицию/паузу и очищает прошлый поток, чтобы после ошибки не запустить прежнюю озвучку вместо выбранной.
